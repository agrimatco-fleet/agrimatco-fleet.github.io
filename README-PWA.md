# نسخة PWA لتطبيق السائق (آيفون)

## الملفات
index.html — التطبيق كاملاً | manifest.webmanifest | sw.js | icons/

## النشر (يجب HTTPS)
أسهل طريقة مجانية: GitHub Pages (ارفع محتوى المجلد إلى مستودع وفعّل Pages) أو Firebase Hosting أو Netlify.

## على الآيفون
1. افتح الرابط في Safari
2. زر المشاركة ثم "إضافة إلى الشاشة الرئيسية"
3. افتح التطبيق من الأيقونة وسجّل الدخول بنفس اسم المستخدم وكلمة المرور

## ملاحظات
- يستخدم نفس حساب السائق وقاعدة Firebase وقواعدها، فلا تغيير في برنامج المدير.
- الإرسال في الخلفية غير متاح على iOS: يُرسل عند فتح التطبيق أو عودة الإنترنت وهو مفتوح.
- API Key في index.html (أعلى السكربت) هو نفسه في google-services.json، وهو مفتاح عميل وليس سراً.
